内心小孩 MBTI 测试 — 源码分模块说明
=====================================

index.html          完整单文件（1593 行，直接用这个）

按模块拆分（便于阅读，按顺序拼接即为完整文件）：
  01-head-and-css.html    第 1-509 行   <head> + 全部 CSS（含明暗主题变量）
  02-body-markup.html     第 510-684 行 页面骨架：顶栏、面包屑、正文、侧栏目录、页脚
  03-quiz-data.js         第 685-870 行 28 道题的题库数据 QUESTIONS
  04-mascots.js           第 871-1217 行 16 个 Q 版 SVG 形象 + 配色/人设映射
  05-types.js             第 1218-1301 行 16 种结果的文案数据 TYPES
  06-app-logic.js         第 1302-1593 行 答题逻辑、计分、结果渲染、分享、主题、滚动

注意：JS 分片不含 <script> 结束标签，拼接时需自行补 </script></body></html>。
